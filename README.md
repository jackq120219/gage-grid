# Gage Grid

Gage Grid is an industrial site-capacity intelligence prototype designed to answer a higher-value question than simple infrastructure proximity: **can a specific site support a specific industrial project before capital is committed?**

## V2 decision engine

The current prototype includes:

- A project/site feasibility desk for power, water, wastewater, gas, and fiber requirements.
- Risk-adjusted usable-capacity calculations based on evidence quality and user risk posture.
- Project-type presets for data centers, advanced manufacturing, food processing, cold storage, battery manufacturing, warehouses, and custom industrial loads.
- Bottleneck detection, feasibility scoring, indicative infrastructure lead-time checks, verification burden, and recommended next diligence action.
- A 12-node Midwest pilot portfolio with 60 simulated capacity records.
- Portfolio ranking, searchable/filterable capacity registry, change-detection examples, site records, local saved screens, and exportable feasibility snapshots.
- Responsive UI and explicit labeling that pilot records are simulated and are not utility commitments or engineering determinations.

## Data standard for production

Production records should be source-backed and carry at minimum: source URI/document, retrieval date, service territory, methodology, evidence status, confidence, infrastructure lead-time assumptions, known downstream constraints, and utility verification status.

The product is intended as a pre-diligence prioritization and decision-intelligence layer, not a substitute for utility studies or professional engineering work.
